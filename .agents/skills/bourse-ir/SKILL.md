# bourse-ir: تحلیل سهام بورس تهران

`${CLAUDE_SKILL_DIR}` پوشهٔ همین اسکیل است. همهٔ اسکریپت‌ها فقط با کتابخانهٔ استاندارد Python 3 کار
می‌کنند و خروجی را در پوشهٔ `bourse/` در پوشهٔ کاری فعلی می‌نویسند (با متغیر `BOURSE_DIR` قابل تغییر).

## قاعده‌های غیرقابل نقض

۱. هیچ عددی ساخته نمی‌شود. هر عدد گزارش باید از خروجی اسکریپت‌ها، فایل کاربر یا سند کدالی که واقعاً
باز شده بیاید. هر چه نیست با «⛔ ناموجود» می‌ماند و به کاربر گفته می‌شود چرا.

۲. پیش از هر تحلیل زنده، `tse.py check` اجرا می‌شود. اگر TSETMC در دسترس نیست (معمولاً در محیط ابری
خارج از ایران)، به کاربر بگو و راه فایل را پیشنهاد کن؛ تحلیل را از حافظه یا حدس نساز.

۳. خروجی، تحلیل داده و برنامه بر پایهٔ قواعد خود کاربر است، نه توصیهٔ خرید و فروش. هیچ سفارشی ارسال
نمی‌شود؛ کارگزاری‌های ایرانی API عمومی ندارند و برگهٔ سفارش برای ثبت دستی است.

۴. اگر نتیجهٔ شبیه‌سازی یا شواهد با انتظار کاربر نمی‌خواند، همان را صریح بگو.

## گردش کار با یک نماد

```bash
S="${CLAUDE_SKILL_DIR}/scripts"
python3 "$S/tse.py" check                 # ۰. دسترسی به TSETMC و کدال
python3 "$S/analyze.py" فزر               # ۱. تحلیل: bourse/analysis-فزر.md و .json
python3 "$S/plan.py" فزر                  # ۲. ورود، حد ضرر، هدف، حجم: bourse/plan-فزر.json
python3 "$S/simulate.py" فزر              # ۳. احتمال هدف و حد ضرر: bourse/sim-فزر.json
python3 "$S/codal.py" فزر                 # ۴. آخرین صورت‌های مالی و گزارش‌های ماهانه با پیوند
python3 "$S/chart.py" فزر                 # ۵. نمودار: bourse/chart-فزر.svg
```

وقتی کاربر فقط می‌گوید «فزر را تحلیل کن»، گام‌های ۰، ۱، ۴ و ۵ را اجرا کن و گزارش را به فارسی روان
خلاصه کن. گام‌های ۲ و ۳ را وقتی اجرا کن که کاربر برنامهٔ معامله، حد ضرر، هدف، تعداد سهم یا احتمال
موفقیت بخواهد، یا پس از تحلیل پیشنهادش را بدهی.

اگر نماد مبهم بود (`نماد دقیقاً پیدا نشد`)، `tse.py search <بخشی از نام>` را اجرا کن و گزینه‌ها را به
کاربر نشان بده؛ برای ادامه از `--ins` استفاده کن. نمادهای حق تقدم و غیرفعال در اولویت آخر قرار می‌گیرند.

### گزینه‌های plan.py

| گزینه | معنا |
|---|---|
| `--entry 1250` | قیمت ورود؛ پیش‌فرض آخرین معامله یا پایانی |
| `--stop support` | پیش‌فرض: نیم ATR زیر نزدیک‌ترین حمایت؛ اگر حمایت دور باشد ۲ ATR |
| `--stop atr --atr-mult 2` / `--stop pct --stop-value 7` / `--stop price --stop-value 1180` | روش‌های دیگر حد ضرر |
| `--target 2r` | پیش‌فرض؛ یا `1r`، `3r`، `resistance`، `price --target-value` |

حد ضرر بالای ورود یا هدف زیر ورود رد می‌شود. اگر حتی یک سهم در محدودیت‌ها جا نشود، برنامه رد می‌شود و
دلیلش گفته می‌شود.

### تنظیمات کاربر

اگر `bourse/config.json` نیست، `config.example.json` همین پوشه را کپی کن و از کاربر بپرس: بودجه (ریال)،
حداکثر زیان هر معامله (ریال)، سقف هر موقعیت (٪ بودجه)، ذخیرهٔ نقد (٪)، و نرخ کارمزد خرید و فروش
کارگزاری‌اش. نرخ کارمزد را حدس نزن؛ تا کاربر نگوید، صفر می‌ماند و برنامه هشدار می‌دهد. ارقام را به ریال
ذخیره کن (تومان × ۱۰).

## اسکن بازار

```bash
python3 "$S/scan.py" فزر فولاد شپنا              # فهرست دلخواه
python3 "$S/scan.py" --file bourse/watchlist.txt
python3 "$S/scan.py" --market --min-value 5e10    # همهٔ سهام بورس و فرابورس با ارزش معامله ≥ ۵ میلیارد تومان
python3 "$S/scan.py" --market --only breakout,real_money
```

ستاپ‌ها: شکست سقف ۲۰ روزه، بازگشت بالای میانگین ۲۰، اشباع فروش، برگشت از اشباع فروش، ورود پول حقیقی با
قدرت خریدار ≥ ۱٫۵، حجم ≥ ۲ برابر میانگین، و صف خرید. اسکن کل بازار برای هر سهم دو درخواست می‌فرستد و با
فاصله اجرا می‌شود (چند دقیقه)؛ اجرای دوباره در همان روز از حافظهٔ موقت خوانده می‌شود. پس از اسکن، برای
نمادهای برتر `analyze.py` را اجرا کن.

## وقتی TSETMC در دسترس نیست

کاربر سابقهٔ قیمت را از صفحهٔ نماد در TSETMC (خروجی Excel یا CSV سابقه) یا از ره‌آورد ۳۶۵ ذخیره می‌کند
و می‌فرستد. سپس:

```bash
python3 "$S/tse.py" import-csv path/to/file.csv --symbol فزر   # یا .xlsx
python3 "$S/analyze.py" فزر --offline
```

سرستون‌های فارسی و انگلیسی (تاریخ، اولین، بیشترین، کمترین، پایانی، حجم، `<DTYYYYMMDD>`، `<CLOSE>` …) و
تاریخ شمسی یا میلادی شناخته می‌شوند. بدون ستون «قیمت دیروز»، قیمت‌ها برای افزایش سرمایه تعدیل نمی‌شوند؛
این را در گزارش بگو. دادهٔ حقیقی و حقوقی از فایل قیمت نمی‌آید و آن بخش «⛔» می‌ماند. اگر کاربر فقط تصویر
چارت فرستاد، از اسکیل `technical-analyst-fa` استفاده کن.

## بخش بنیادی

`codal.py` فهرست آخرین اطلاعیه‌ها را با نوع (صورت مالی، گزارش ماهانه، مجمع، افزایش سرمایه، پیش‌بینی) و
پیوند می‌دهد، اما ارقام را از اطلاعیه‌ها استخراج نمی‌کند. برای تحلیل درآمد و سود، پیوند را باز کن (اگر
در دسترس است) یا از کاربر بخواه جدول را بفرستد، و فقط ارقام همان سند را نقل کن. EPS، P/E، P/E گروه،
تعداد سهام و دامنهٔ نوسان از TSETMC می‌آیند.

## تحویل

گزارش را به فارسی رسمی و پیوسته بنویس و جدول‌های اسکریپت را نگه دار. اگر کاربر سند Word خواست، با اسکیل
docx سند راست‌به‌چپ کامل (bidi در پاراگراف‌ها، visuallyRightToLeft در جدول‌ها، فونت B Nazanin) بساز و
نمودار SVG را هم جاسازی کن و هم جداگانه تحویل بده. تاریخ‌ها را شمسی بنویس. در پایان همیشه بگو کدام
بخش‌ها ناموجود ماند.

## فایل‌ها

| فایل | محتوا |
|---|---|
| `bourse/config.json` | قواعد کاربر (بودجه، ریسک، کارمزد) |
| `bourse/analysis-<نماد>.json` و `.md` | خروجی تحلیل |
| `bourse/bars-<نماد>.json` | سابقهٔ روزانهٔ تعدیل‌شده |
| `bourse/plan-<نماد>.json` | برنامهٔ معامله |
| `bourse/sim-<نماد>.json` | نتیجهٔ شبیه‌سازی |
| `bourse/codal-<نماد>.json` | اطلاعیه‌های کدال |
| `bourse/chart-<نماد>.svg` | نمودار |
| `bourse/watchlist.json` | نتیجهٔ اسکن |
| `bourse/cache/` | پاسخ‌های TSETMC و کدال |

جزئیات منابع، نگاشت فیلدها، روش تعدیل و فرمول‌ها در `references/data-sources.md` و `references/method.md`
است. آزمون آفلاین: `python3 "${CLAUDE_SKILL_DIR}/tests/selftest.py"`.
