# آرا | دلال هوشمند املاک شمال

آرا یک وب‌سایت فارسی و راست‌به‌چپ برای جست‌وجو، مقایسه و ثبت آگهی ملک در ۳۹ شهر استان‌های گیلان، مازندران و گلستان است. هسته آن جست‌وجو به زبان طبیعی است: کاربر جمله‌ای مانند «ویلای استخردار در رامسر با دید دریا زیر ۲۰ میلیارد» می‌نویسد و سامانه شهر، نوع معامله، نوع ملک، بودجه، متراژ، تعداد خواب و امکانات را از آن استخراج می‌کند، فیلترها را تنظیم می‌کند و نتایج را هم‌زمان روی فهرست و نقشه نشان می‌دهد.

> **وضعیت فعلی:** نسخه نمایشی (فرانت‌اند کامل، بدون سرور). همه آگهی‌ها و قیمت‌ها **نمونه و ساختگی** هستند و با برچسب «آگهی نمونه» مشخص شده‌اند. پیش از انتشار عمومی باید با داده واقعی جایگزین شوند.

## اجرا

نیازی به نصب یا build نیست.

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

برای انتشار، کل پوشه را روی هر میزبان استاتیک (GitHub Pages، Netlify، Cloudflare Pages، یا هاست ایرانی مانند لیارا و آروان) بارگذاری کنید. فونت وزیرمتن و کتابخانه نقشه Leaflet داخل پروژه قرار گرفته‌اند تا سایت به CDN خارجی وابسته نباشد. تنها وابستگی بیرونی، کاشی‌های نقشه OpenStreetMap است.

## ساختار پروژه

```
index.html              صفحه اصلی
assets/css/style.css    سیستم طراحی (توکن‌های رنگ، حالت تیره، واکنش‌گرایی)
assets/js/data.js       استان‌ها، شهرها، انواع ملک، امکانات و مولد آگهی نمونه
assets/js/nlp.js        موتور فهم زبان فارسی (قاعده‌محور)
assets/js/app.js        رابط کاربری، نقشه، دستیار، مقایسه، ثبت آگهی، ابزارها
assets/vendor/          Leaflet 1.9.4 و فونت Vazirmatn (هر دو با مجوز آزاد)
```

## مسیر تبدیل به محصول واقعی

۱. **سرور و پایگاه داده:** یک API (مثلاً FastAPI یا Node/NestJS با PostgreSQL و PostGIS) با مسیرهای `GET /listings`، `POST /listings`، `GET /cities`. در `app.js` کافی است آرایه `ALL` از این API پر شود.

۲. **اتصال مدل زبانی:** تابع `NLP.parseQuery` را با فراخوانی یک مدل زبانی جایگزین کنید که خروجی JSON با همان ساختار (`city`, `deal`, `types`, `min`, `max`, `areaMin`, `rooms`, `amenities`, ...) برگرداند. موتور قاعده‌محور فعلی به‌عنوان پشتیبان در صورت قطع سرویس باقی بماند.

۳. **احراز هویت و اعتماد:** ورود با کد یک‌بارمصرف پیامکی، پنل مشاوران املاک، فرایند تأیید آگهی (بررسی سند و کد رهگیری)، گزارش تخلف.

۴. **تصاویر:** بارگذاری عکس واقعی ملک به جای تصویرسازی برداری فعلی (فشرده‌سازی و WebP سمت سرور).

۵. **داده قیمت:** ابزار تخمین ارزش اکنون از میانه آگهی‌های نمونه استفاده می‌کند؛ برای استفاده واقعی باید به داده معاملات یا آگهی‌های واقعی و پالایش‌شده متصل شود.
