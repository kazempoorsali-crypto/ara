# آرا | دلال هوشمند املاک و خودروی شمال

آرا سایت دلالی املاک و خودرو برای ۳۹ شهر گیلان، مازندران و گلستان است. آگهی‌های عمومی دیوار را به‌تدریج و با سقف درخواست ساعتی گردآوری می‌کند. قیمت هر آگهی را با میانه آگهی‌های مشابه همان شهر می‌سنجد و همه دکمه‌های تماس و درخواست بازدید را به شماره و حساب شما (کارگزار) وصل می‌کند.

## اجرا روی رایانه شما

۱. پایتون ۳ را نصب کنید ([python.org/downloads](https://www.python.org/downloads/)). در ویندوز هنگام نصب گزینه **Add python.exe to PATH** را تیک بزنید. هیچ کتابخانه دیگری لازم نیست.

۲. پوشه پروژه را دانلود کنید (در گیت‌هاب: Code ← Download ZIP) و از حالت فشرده خارج کنید.

۳. اجرا:
   - **ویندوز:** روی `start-windows.bat` دوبار کلیک کنید.
   - **مک یا لینوکس:** در ترمینال `./start-mac-linux.sh` را اجرا کنید.

   مرورگر خودکار نشانی `http://127.0.0.1:8000` را باز می‌کند. پنجره سیاه سرور باید باز بماند؛ با بستن آن سایت و دریافت آگهی متوقف می‌شوند.

۴. پنل مدیریت را در `http://127.0.0.1:8000/admin.html` باز کنید. بار اول از شما می‌خواهد یک رمز تعیین کنید. سپس به ترتیب این کارها را انجام دهید:
   - **اطلاعات تماس:** شماره تلفن، واتس‌اپ، تلگرام، نام مشاور و متن «درباره ما».
   - **پرداخت و خدمات:** شماره کارت، شبا، نام صاحب حساب، بانک و تعرفه خدمات. هیچ تعرفه‌ای از پیش تعیین نشده است.
   - **دریافت از دیوار:** شهرها و دسته‌ها را انتخاب کنید. «آزمون اتصال» را بزنید و سپس دریافت خودکار را روشن کنید.

تا وقتی آگهی واقعی دریافت نشده، سایت آگهی‌های **نمونه و ساختگی** نشان می‌دهد و نوار بالای صفحه این را اعلام می‌کند. این حالت در پنل، بخش «اطلاعات تماس ← تنظیمات نمایش»، خاموش می‌شود.

## دریافت تدریجی از دیوار

| | |
|---|---|
| روش پیش‌فرض | سرور MCP عمومی دیوار [mmdju/divar-mcp](https://github.com/mmdju/divar-mcp)، با ابزارهای `search_ads` و `ad_details`. کلید لازم ندارد و شهر را با نام فارسی می‌پذیرد. |
| روش جایگزین | اتصال مستقیم به همان نقاط پایانی JSON که وب‌اپ دیوار و [shojaee76-cmyk/divar-mcp](https://github.com/shojaee76-cmyk/divar-mcp) استفاده می‌کنند. به شناسه عددی شهر نیاز دارد که پنل آن را خودکار کشف می‌کند. |
| سقف | پیش‌فرض **۶۰ درخواست در ساعت** (یک درخواست در دقیقه) و قابل تنظیم. سقف سخت روی ۶۰ دقیقه گذشته هم رعایت می‌شود. |
| ترتیب کار | تازه‌سازی صفحه اول هر فهرست هر ۶ ساعت، دریافت جزئیات (عکس‌ها، متراژ، توضیحات)، پیمایش صفحه‌های بعدی و بازبینی آگهی‌های قدیمی برای تشخیص حذف‌شده‌ها |
| ماندگاری | صفحه و نشانگر هر فهرست در پایگاه داده `data/ara.db` ذخیره می‌شود. پس از خاموش و روشن شدن رایانه، کار از همان‌جا ادامه می‌یابد. |
| خطا | با خطای ۴۲۹ (درخواست زیاد) یا خطای شبکه، فاصله درخواست‌ها به‌صورت نمایی بیشتر می‌شود. |

هر درخواست فهرست ۲۴ تا ۳۰ آگهی خلاصه برمی‌گرداند و هر درخواست جزئیات یک آگهی کامل. با سقف ۶۰ درخواست و نسبت پیش‌فرض (۲ جزئیات به ازای هر صفحه فهرست)، در هر ساعت حدود ۲۰ صفحه فهرست، یعنی ۴۸۰ تا ۶۰۰ آگهی خلاصه، و حدود ۴۰ آگهی کامل دریافت می‌شود. پوشش کامل شهرهای پرآگهی چند روز طول می‌کشد. شماره تلفن آگهی‌دهندگان در هیچ‌کدام از دو روش در دسترس نیست، چون به ورود خود فروشنده نیاز دارد. به همین دلیل همه تماس‌ها به شماره شما می‌آید.

> **ملاحظه حقوقی:** پیش از انتشار عمومی، قوانین استفاده از دیوار را درباره بازنشر آگهی بررسی کنید. سایت در هر آگهی منبع را ذکر و پیوند آگهی اصلی را نمایش می‌دهد.

## ساختار

```
index.html, admin.html        صفحه‌های سایت و پنل
assets/css/style.css          سیستم طراحی «خزر» (روشن و تیره)
assets/js/data.js             شهرها، دسته‌ها و آگهی‌های نمونه
assets/js/nlp.js              فهم جمله فارسی (ملک و خودرو)
assets/js/api.js              لایه داده: سرور محلی یا حالت نمونه
assets/js/ui.js, app.js       کارت، نمودار، نقشه و صفحه‌ها
assets/js/admin.js            پنل مدیریت
server/app.py                 سرور HTTP، API و پنل (فقط کتابخانه استاندارد پایتون)
server/store.py               SQLite: آگهی‌ها، تاریخچه قیمت، درخواست‌ها، تنظیمات
server/ingest.py              زمان‌بندی دریافت تدریجی با سقف ساعتی
server/divar_client.py        اتصال MCP و اتصال مستقیم به دیوار
server/catalog.py             شهرها، دسته‌ها و تبدیل آگهی خام به ساختار یکسان
tests/                        شبیه‌ساز دیوار و آزمون یکپارچه (python tests/test_backend.py)
```
